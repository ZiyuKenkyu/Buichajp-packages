ぶいちゃライブ パネル (VRChat ワールド用)  version 1.0.0
==========================================================

ぶいちゃライブ (https://live.buicha.jp) の配信を、VRChat のワールドで映すスクリーンと操作パネルです。
English: README_EN.txt


入れ方
------
VRChat Creator Companion (VCC) で入れます。
1. VCC の Settings → Packages → Add Repository に https://packages.buicha.jp/vpm.json を入れます
   (https://packages.buicha.jp の「VCC に追加」ボタンでも追加できます)。
2. プロジェクトの Manage Project で「Buicha Live Player」を追加します。
   VRChat SDK - Worlds 3.10 以上が必要です (VCC が自動で入れます)。
ファイルは Packages/jp.buicha.live.player/ に入ります (Project ウィンドウの Packages → Buicha Live Player)。


入っているもの
--------------
BuichaLive.prefab               4 チャンネルモード。チャンネルを 4 つ切り替えられます (パネル 3.2m × 0.69m)
BuichaLiveStage.prefab          ステージモード。配信は 1 本だけの小さいパネルです (2.0m × 0.6m)
Scripts/                        動作のスクリプト (UdonSharp)
Shaders/ Materials/ Textures/ Fonts/   見た目に使うもの


使い方
------
1. どちらかのプレハブを Packages → Buicha Live Player からシーンに置きます (両方置いても動きます)。
   パッケージの中のファイルは書き換えず、シーンに置いたものを調整してください (更新のときに上書きされます)。
2. スクリーン (Screen) とパネル (Panel) の位置は、プレハブの中で自由に動かしてかまいません。
3. ViewAreas の中のキューブ (Area) が「映像を流す範囲」です。この中に頭がある人だけ映像が再生されます。
   位置・大きさ・回転を変える、複製して増やす、どれも自由です。全部消すと、スクリーンからの距離
   (Panel の Cutoff Distance) で判断します。
4. 必要なら、プレハブのルート (BuichaLive / BuichaLiveStage) の「Buicha Live Settings」を設定します。
   - Language: パネルの文言を日本語 (Japanese) と英語 (English) で切り替えます。
   - Sync Channel Switch: オンにすると、誰かがチャンネルを切り替える・止めると全員の画面が変わります。
     オフ (初期値) では、切り替えと停止はその人の画面だけです。ステージモードはいつもオンと同じです。
   - Auto Play Url: 最初に自動で再生する動画の URL。インスタンスを最初に開いた人がチャンネル 1
     (ステージモードはステージ) に入れて再生し、後から来た人にも同じものが映ります。空なら何もしません。
     普通のチャンネルと同じ扱いなので、ワールドの中で ✕ を押せば消せます。
   - Auto Play Loop: 自動再生の動画を繰り返します (配信には効きません)。
   - Idle Texture: 何も映っていないとき (停止中・接続中・範囲の外) にスクリーンに出す画像。
     16:9 に引き伸ばして表示します。空なら付属の画像 (Textures/BuichaLiveIdleImage.jpg) です。
5. ワールドをアップロードします。


ワールドでの操作
----------------
- チャンネルを選び、「URL を再生」か「BuichaLive でライブ配信」を選びます。
- URL を再生: YouTube などの動画の URL や、dash.live.buicha.jp で発行した rtspt://live.buicha.jp/... を貼って「再生」。
- BuichaLive でライブ配信: 「同意してコードを発行」を押すと、押した本人にだけコードとリンクが出ます。
  リンクを VRChat のコピー機能でコピーして PC のブラウザで開くと、コードが入った状態で開きます。
  (https://dash.live.buicha.jp/claim を開いてコードを手で入れても同じです。) 規約に同意して進むと、配信の設定が表示されます。
  コードは 10 分で失効します。
- 丸いボタンは左から 消す / 止める / つなぎ直す です。
- チャンネルに何が入っているかと、消す (✕) は全員で共有です。見るチャンネルの切り替えと止める (■) は、
  初期設定ではその人の画面だけに効きます。ほかの人がチャンネルを始めても、見ている人の画面は変わりません。
  何も見ていない人 (入ってきたばかりの人など) は、誰かが始めたチャンネルを見ます。
- 動画を再生しているときは、パネル上段に再生バーが出ます。動かすと、その場の全員の再生位置が変わります。
  後から来た人も、同じ位置から再生されます (配信には再生バーは出ません)。


知っておいてほしいこと
----------------------
- このパネルの「同意してコードを発行」で始めた配信は公開で、インスタンスの外からも視聴できます。
  限られた相手にだけ見せたいときは、dash.live.buicha.jp で発行した URL をパネルに貼ってください。
- ぶいちゃライブの配信を見るには、VRChat の設定で「信頼されていない URL を許可 (Allow Untrusted URLs)」を
  オンにする必要があります。オフの人には、VRChat が認めたサイト (YouTube など) の動画だけが映ります。
- このパネルが接続するのは次のサーバーと、誰かがパネルに貼った URL のサイトです。貼った URL はサイトで止めず、
  その場の全員がそのサイトに接続します (普通の動画プレイヤーと同じです)。接続すると、相手には IP アドレスが伝わります。
    live.buicha.jp        映像 (RTSP)
    dash.live.buicha.jp   発行と、配信中かどうかの確認 (HTTPS)
- パネルは誰でも操作できます (チャンネルを消す・止めるも含みます)。
- 1 つの配信を同時に見られるのは 30 接続までです。
- 「同意してコードを発行」で使えるチャンネルは、このパネルを置いたすべてのワールドで共有しています。
  混み合っていると発行できないことがあります。
- ブラウザからの配信は、サーバー全体で同時に 2 本までです (OBS での配信は対象外)。
- 動作を確認しているのは Windows (PC) です。Quest 単体での再生は保証していません。
- Panel の「チャンネルプール」の URL は変更しないでください。発行が動かなくなります。
- ぶいちゃライブの利用規約: https://dash.live.buicha.jp/terms
